# 🎒 学习小管家 —— 学生学习记录系统

一套面向中小学生的桌面应用，记录语文 📚、数学 🔢、英语 🔤 三科的每日学习打卡，
并能把统计报告**定时自动发送到家长邮箱**。界面采用明亮童趣的配色，操作简单。

## ✨ 功能

1. **登录系统** —— 学生可自助注册，管理员账号统一管理。
   - **记住我**：登录时勾选「记住我」，下次打开程序自动登录、无需再输入；
     点「退出登录」会清除该记忆，方便切换账号。
2. **每日打卡** —— 按科目记录学习时长、学习内容和心情，自动统计连续打卡天数。
   - **计时打卡**：点击「▶ 开始计时」开始学习，结束时点「⏹ 结束计时并完成」，
     系统自动按实际用时生成打卡记录，无需手动填时长。
   - **手动打卡**：也可直接选时长、点「✅ 完成打卡」。
3. **修改 / 删除记录** —— 在「最近的记录」里点击任意一条，即可打开修改框，
   调整科目、日期、时长、内容、心情，或直接删除。
4. **学习统计** —— 按「今天 / 近 7 天 / 近 30 天」查看各科目时长的可视化条形图。
5. **定时邮件** —— 每天（或每周）定时把全体学生的学习汇总发到家长邮箱；
   默认收件人 `416091859@qq.com`，管理员可在「管理中心」随时增删邮箱。

## 🚀 运行方法

需要 **Python 3.10+**（Windows 安装包自带 Tkinter，无需额外安装第三方库）。

```bash
python main.py
```

首次运行会自动创建数据库 `data/study.db` 并生成默认管理员账号。

| 角色 | 账号 | 密码 |
| ---- | ---- | ---- |
| 管理员 | `admin` | `admin123` |

> 登录后请尽快在「修改密码」处更换管理员密码。

## 📮 配置邮箱（重要）

定时邮件需要一个**发件邮箱**。以 QQ 邮箱为例：

1. 登录 QQ 邮箱网页版 → 设置 → 账户 → 开启「POP3/SMTP 服务」。
2. 按提示获取一串**授权码**（注意：不是 QQ 登录密码）。
3. 打开本程序，用 `admin` 登录 → 「🛠 管理中心」→「📮 发件邮箱设置」：
   - SMTP 服务器：`smtp.qq.com`
   - 端口：`465`
   - 发件邮箱：你的 QQ 邮箱地址
   - 授权码：上一步获取的授权码
4. 点击「💾 保存设置」，再点「✉️ 发送测试邮件」验证是否成功。

配置好后，可在「⏰ 定时发送设置」里设定每天发送时间（默认 20:00），
程序保持运行时会自动在该时间发送汇总报告。

## 🗂 项目结构

```
学生学习记录系统/
├── main.py                 # 程序入口
├── config.json             # SMTP / 定时 / 默认收件人配置
├── data/study.db           # SQLite 数据库（首次运行自动生成）
├── README.md
└── src/
    ├── config.py           # 配置读写
    ├── database.py         # 数据库（用户 / 打卡 / 收件人 / 统计）
    ├── stats.py            # 报告生成（文本 + HTML）
    ├── email_service.py    # 邮件发送 + 后台定时线程
    └── ui/
        ├── theme.py        # 童趣主题（配色 / 字体 / 按钮）
        ├── login_window.py # 登录 / 注册
        ├── main_window.py  # 主窗口 + 导航
        ├── checkin_frame.py# 每日打卡
        ├── stats_frame.py  # 学习统计
        └── admin_frame.py  # 管理中心
```

## 🔒 说明

- 密码使用 PBKDF2-SHA256 加盐哈希存储，不保存明文。
- 「记住我」凭据用 base64 编码保存在本地 `data/remember.json`（仅防肉眼直读，非加密），
  退出登录即清除；请勿将该文件分享给他人。
- 邮箱授权码保存在本地 `config.json`，请勿将该文件分享给他人。
- 定时发送依赖程序保持运行；关闭程序则不会发送。
